# Runtime-only dependencies for the learned router (ossp_router.learned_router
# -> router.RouterPipeline). Installed at image BUILD time only (container/
# Dockerfile); the running container makes no network calls (docs/RUNTIME.md).
#
# Deliberately narrower than router/requirements.txt: pandas/pyarrow/pytest are
# dev/offline-training-only (router/ossp_adapter.py, router/scripts/train.py) --
# ossp_router.learned_router reads InputBatch JSON directly and calls
# RouterPipeline.estimate_texts()/predict_texts(), never pandas. onnxruntime is
# not used because EMBEDDING_BACKEND="sentence_transformers" (router/config.py).
# Leaving either out of this file keeps them out of the submission image
# entirely (image-size risk, see docs/RUNTIME.md's 1 GiB compressed-layer /
# 2 GiB rootfs limits).
#
# torch is intentionally NOT listed here even though sentence-transformers
# needs it -- container/Dockerfile installs it in a separate, earlier pip
# invocation from PyTorch's CPU-only index, because the plain PyPI "torch"
# wheel for linux/aarch64 pulls in multi-GB NVIDIA CUDA libraries this
# CPU-only, GPU-less container never uses.
lightgbm>=4.0,<4.6
scikit-learn>=1.3,<1.6
numpy>=1.24,<2
scipy>=1.10,<2
joblib>=1.3,<2
sentence-transformers>=2.2,<3
